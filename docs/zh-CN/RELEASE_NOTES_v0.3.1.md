# Douban Archive v0.3.1 发布说明

这是 Douban Archive 的第一版公开发布候选版本。

Douban Archive 是一个本地优先的豆瓣个人数据归档工具。它帮助用户把自己在豆瓣上积累的书影音、广播、日记和评价记录导出到本地，为长期备份和未来 AI 兴趣分析做准备。

## 亮点

- 支持导出图书、电影、音乐记录
- 支持导出广播、日记和长评，当前为实验性功能
- 支持评分、标签、短评、正文、时间和链接等字段
- 支持 JSON、Excel CSV、Markdown 三种格式
- Excel CSV 已修复中文乱码问题
- 支持后台导出，关闭插件弹窗后任务仍会继续
- 支持全选、核心导出、分类自选
- 提供中英文 README、用户手册、隐私政策、安全说明和风险发布指南

## 推荐格式

- JSON：最适合长期备份和 AI 分析
- Excel CSV：最适合表格筛选和统计
- Markdown：最适合阅读、Obsidian 和 GitHub 归档

## 隐私与边界

Douban Archive 只在用户本地浏览器运行，不上传导出数据，不收集密码、Cookie 或 token。

这个工具只用于备份用户自己登录后本来可以访问的数据，不用于绕过验证码、登录、权限、付费限制或平台风控。

## 已知限制

- 日记和长评仍属于实验性支持
- 豆瓣页面结构可能变化，后续需要根据真实样本持续适配
- 暂不支持断点续传
- 暂不支持真正的 `.xlsx` 文件导出
