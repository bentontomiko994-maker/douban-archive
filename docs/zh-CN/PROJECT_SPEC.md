# 项目规格：Douban Archive

## 一句话

将用户自己在豆瓣上的书影音记录导出为本地文件，为未来的个人数据备份和 AI 兴趣画像打基础。

## 用户

主要用户是豆瓣活跃用户，以及担心平台衰退、功能下线或个人数据无法完整取回的用户。

## 第一版范围

第一阶段优先做书影音收藏导出：

- 图书：读过、想读、在读
- 电影：看过、想看、在看
- 音乐：听过、想听、在听

v0.2.0 加入实验性导出：

- 广播 / 记录
- 日记

v0.3.0 加入：

- 评分数据标准化导出
- 短评、长评、日记正文导出
- 全选与分类自选
- Excel 直接打开 CSV 时正确显示中文

暂不做小组帖子和评论。

## 关键原则

- 本地优先
- 隐私优先
- 不上传用户数据
- 不绕过平台访问控制
- 导出任务应在后台运行，不因 popup 弹窗关闭而中断
- 优先保证可运行、可导出、可迭代

## 验收标准

- 用户可以在 Chromium 浏览器中加载插件
- 用户可以填写豆瓣用户 ID
- 用户可以选择导出范围
- 用户可以一键全选，也可以按图书、电影、音乐、广播日记、评价分类选择
- 用户可以导出 JSON、Excel CSV 或 Markdown
- 导出内容包含标题、链接、评分、评分比例、标签、短评、长评正文、日记正文、收藏日期等字段
- 用户关闭插件弹窗后，后台导出任务继续运行
- README 提供中英双语说明
