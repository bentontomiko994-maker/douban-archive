# Douban Archive 用户手册

Douban Archive 是一个本地优先的浏览器扩展，用来导出你自己在豆瓣上的书影音、广播、日记和评价记录。

## 1. 适合谁使用

适合这些用户：

- 长期使用豆瓣记录书影音的人
- 想把自己的豆瓣数据备份到本地的人
- 担心平台变化、功能下线或账号风险的人
- 希望未来让 AI 更了解自己兴趣偏好的人

## 2. 安装方式

1. 下载项目压缩包并解压。
2. 找到解压后的 `extension` 文件夹。
3. 打开 Chrome、Edge、Arc 或其他 Chromium 浏览器。
4. 在地址栏输入 `chrome://extensions`。
5. 打开右上角的 `开发者模式`。
6. 点击 `加载已解压的扩展程序`。
7. 选择 `extension` 文件夹。
8. 在同一个浏览器里登录豆瓣。
9. 点击浏览器工具栏里的 Douban Archive 图标。

## 3. 基本使用

1. 输入你的豆瓣用户 ID。
2. 选择导出范围。
3. 选择导出格式。
4. 设置请求间隔，默认值通常即可。
5. 点击 `开始导出`。
6. 导出开始后，可以关闭弹窗或切换页面。
7. 重新点击插件图标，可以查看进度。
8. 导出完成后，将文件保存到本地。

## 4. 导出范围

当前支持：

- 图书：读过、想读、在读
- 电影：看过、想看、在看
- 音乐：听过、想听、在听
- 广播 / 记录
- 日记
- 长评 / 评价

界面中可以使用：

- `全选`：导出全部支持内容
- `核心`：只导出读过、看过、听过
- `清空`：取消全部选择
- `图书`、`电影`、`音乐`、`广播日记`、`评价`：按分类选择

## 5. 导出格式

### JSON

最适合作为主备份格式，也最适合未来交给 AI 分析。

JSON 会保留结构化字段，例如：

- 类型
- 状态
- 标题
- 链接
- 评分
- 评分比例
- 标签
- 短评
- 日记正文
- 长评正文
- 发布时间

### Excel CSV

适合用 Excel、Numbers 或 Google Sheets 打开，进行筛选、统计和排序。

这个格式已经加入 UTF-8 BOM，Excel 直接打开时应该可以正确显示中文。

### Markdown

适合人类阅读，也适合放进 Obsidian、GitHub 或个人知识库。

如果你想把导出内容作为长期档案阅读，Markdown 很合适。

## 6. 和 AI 结合

如果未来要让 AI 根据你的豆瓣数据理解你的兴趣，建议优先使用 JSON。

原因是 JSON 保留的数据结构最完整，AI 可以更清楚地区分：

- 你高分喜欢什么
- 你低分不喜欢什么
- 你想看但还没看的内容
- 你长期关注的题材
- 你的短评和长评里反复出现的关键词
- 你的兴趣随时间如何变化

## 7. 隐私与安全

Douban Archive 只在本地浏览器运行。

它不会：

- 上传你的导出数据
- 收集你的密码
- 收集你的 Cookie
- 发送分析统计
- 把你的数据交给第三方

导出的文件可能包含私人日记、评价和兴趣记录，请妥善保存，不要随意上传公开平台。

## 8. 合规边界

这个工具只用于备份你自己能访问的数据。

请不要用它：

- 抓取他人的隐私内容
- 绕过验证码
- 绕过登录或权限限制
- 进行批量采集
- 伪装成豆瓣官方工具

如果豆瓣要求验证，请先在浏览器里手动完成验证，再继续导出。

## 9. 常见问题

### 为什么 Excel 打开没有乱码了？

插件导出的 Excel CSV 已经加入 UTF-8 BOM，Excel 会更容易正确识别中文编码。

### 为什么导出速度不快？

插件会主动放慢请求速度，降低失败概率，也减少对豆瓣的访问压力。

### 关闭插件弹窗会停止吗？

不会。导出任务在后台运行。重新点击插件图标可以查看进度。

### 哪个格式最推荐？

长期备份选 JSON；自己阅读选 Markdown；表格分析选 Excel CSV。

### 日记和长评一定能完整导出吗？

它们目前仍属于实验性支持。豆瓣页面结构可能变化，如果导出不完整，需要根据真实页面继续适配。
