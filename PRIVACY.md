# Privacy Policy

Douban Archive is a local-first browser extension for personal data backup.

## What Data Is Processed

The extension can read Douban pages that you can already access in your own logged-in browser session, including selected book, movie, music, status, note, and review pages.

Depending on your export choices, the exported file may include:

- Item titles and URLs
- Collection status
- Ratings
- Tags
- Short comments
- Review content
- Note content
- Status content
- Dates visible on Douban pages

## What Data Is Stored

The extension stores only basic local settings in your browser, such as:

- Douban user ID
- Request delay setting

Exported files are saved directly to your computer through the browser download flow.

## What Data Is Not Collected

Douban Archive does not:

- Upload your exported data to any server
- Send your data to the project author
- Track usage analytics
- Collect passwords
- Collect cookies
- Collect tokens
- Sell or share data with third parties

## Network Access

The extension requests Douban pages from Douban domains only. It does not call any third-party backend controlled by this project.

## User Responsibility

Exported files may contain private personal content. Keep them in a safe location. Do not publish exported files unless you have reviewed and removed private information.
